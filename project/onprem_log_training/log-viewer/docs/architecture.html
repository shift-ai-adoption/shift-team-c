onprem_log_training — 研修環境アーキテクチャ

RoboMart ログ収集研修環境の全体構成 / ログの流れ・TrackID相関・ダッシュボード

サービス構成

  • • training-client — RoboMart Web/API (:3002)
  • • training-server — 業務ロジック API (:4002 / SSH:5101)
  • • log-viewer — ダッシュボード (:LOG_VIEWER_PORT)
  • • タイムゾーン: JST (Asia/Tokyo) 統一

TrackID によるログ相関

  • • client が 7文字の TrackID を発行
  • • X-Track-Id ヘッダで server へ伝播
  • • 両ログに同一 TrackID が記録される
  • • log-viewer が紐づけてインシデント表示

  • • 請求書払い注文確定 → 500
  • • bug-config.json で ON/OFF 切替可
